1. CORE GOAL

Build a lightweight Android application that provides disposable temporary email addresses.

Each mailbox remains active for exactly 7 days.

The user can create a new address at any time.

There is NO cooldown.

The user can change an address even one second after creating the previous one.

Existing mailboxes remain available until their individual expiration.

The user can have multiple active mailboxes.

5. Save the reward state.

If the user closes the ad early:

NO reward.

If the ad fails:

NO reward.

If the ad never loads:

NO reward.
